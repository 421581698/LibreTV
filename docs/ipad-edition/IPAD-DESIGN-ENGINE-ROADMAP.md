# LibreTV iPad Edition — Design Engine 六大技术方向

状态：已纳入项目二产品路线；当前为设计规范与基础能力落地阶段。本文是 iPad Edition Preview 的统一设计与验收依据。

## 产品目标

将 iPad Edition 从单纯的响应式影视网页升级为适合大屏触控的影院交互界面。六个方向共用一套材质、动效、空间层级、手势和性能策略，不允许每个页面各自堆叠效果。

核心原则：
- 内容优先：海报、影片信息和视频画面始终优先于装饰层。
- 渐进增强：Safari 基础体验必须完整；折射、色散和复杂动态效果只能作为能力增强。
- 一致性：所有页面共用设计 token 和交互状态，不复制出多套玻璃样式。
- 可访问：支持键盘、触控、减少动态效果和减少透明度偏好。
- 可测量：每项效果必须有性能预算和降级路径。

## 方向一：Apple Liquid Glass 材质引擎

目标：建立真实的玻璃层次，而不是简单地给所有元素加 blur。

研究与实现：
- 半透明底色、背景模糊与饱和度。
- 玻璃边缘描边、顶部高光、环境光渐变和柔和阴影。
- 在支持的浏览器中按需启用 SVG displacement/refraction、色散和边缘折射。
- 对导航胶囊、侧边栏、搜索/筛选面板、播放工具条使用共享材质 token。
- 不对海报墙、整页内容或视频画面施加全局玻璃覆盖。

兼容策略：
- Safari/WebKit 的基础材质由半透明填充、边缘高光、渐变和 backdrop-filter 组成。
- feDisplacementMap 与色散效果需 feature detection 和实机验证，不作为 Safari 必需能力。
- 不支持滤镜时仍保持足够不透明度、文字对比度和清晰边界。

## 方向二：动态物理动画引擎

统一管理：
- Spring：面板开合、选中态切换、按钮回弹。
- Inertia：可拖动面板、可横向滚动内容轨道。
- Morph：导航选中背景、按钮和面板状态变化。
- Touch feedback：按下、拖动、释放、取消、禁用状态。

规则：
- 动画优先使用 transform/opacity；避免持续改变布局属性。
- 动画时长、阻尼和位移使用共享 token。
- 不得覆盖系统滚动、系统返回手势或播放器手势。
- prefers-reduced-motion: reduce 时关闭非必要运动与惯性。

## 方向三：空间化 UI 引擎

统一 z-index 层级：
1. 内容与媒体层。
2. 页面内轻量控件层。
3. 固定玻璃导航层。
4. 浮动面板/侧栏层。
5. 遮罩与模态交互层。

实现原则：
- 通过层级、阴影、轻微位移和透明度表达景深。
- 浮层打开/关闭应保持空间连续性，避免突然跳层。
- 面板不遮挡关键影片信息，不阻断内容滚动。
- 不使用大面积强透视、持续 3D 旋转或无意义悬浮动画。

## 方向四：自适应材质引擎

需要覆盖：
- 浅色与深色主题。
- 动态海报/背景下的文字对比度。
- iPad 横屏、竖屏、分屏和窗口尺寸变化。
- prefers-reduced-transparency 与 prefers-reduced-motion。

材质必须由 token 驱动：页面底色、玻璃填充、模糊半径、饱和度、边缘、文字、阴影和强调色。动态背景不得直接决定文字颜色；必要时增加独立遮罩保障可读性。

## 方向五：高性能渲染引擎

性能预算与策略：
- 避免在长海报列表中的每张卡片上启用 backdrop-filter 或 SVG displacement。
- 折射只用于少量、静止或低频更新的关键玻璃表面。
- 动画优先 transform/opacity；避免滚动期间高频读取布局。
- 页面进入后台或组件卸载时停止不必要的动画/观察任务。
- 视频播放期间降低非必要的背景动效和滤镜复杂度。
- 对低性能设备提供低效果模式；基础交互与内容不能被降级掉。

验证指标：
- 滚动、点击和面板开合无明显卡顿。
- 视频播放期间不出现由装饰动画导致的明显掉帧。
- 无持续增长的事件监听器、动画帧或内存占用。
- 用真实 iPad Safari 验证；桌面 Chromium 结果不能代替 iPad 验收。

## 方向六：触控与手势交互引擎

交互覆盖：
- Tap：即时按压态与清晰的操作目标。
- Long press：海报快捷操作，需避免与系统文本选择/页面上下文菜单冲突。
- Drag：只在明确可拖动的把手或区域启用。
- Swipe：内容轨道使用原生横向滚动与 scroll-snap；侧栏手势需避免与系统边缘返回冲突。
- Transition：详情、筛选、侧栏和播放面板采用一致的进入/退出节奏。
- Keyboard/trackpad：焦点可见、Escape 关闭浮层、合理的 hover 与 focus 状态。

所有触控操作必须有非手势替代入口；触控区域以约 44 CSS px 为目标，紧凑布局也不得让主要操作难以点击。

## 当前落地基线

- 已接入 liquid-glass-react 的导航玻璃增强层，并保留独立清晰的 SVG 图标和文字层。
- 已有统一的导航、侧栏和内容 SVG 图标风格。
- 已有安全区适配、侧栏遮罩、Escape 关闭和减少动态效果基础规则。
- 本次增量建立共享材质/空间/动效 token、按压反馈、焦点可见性和减少透明度降级。
- 不在本阶段宣称已完成完整折射、惯性拖拽或全局手势系统；这些必须逐项实现和实机验收。

## 实施顺序

1. 材质基线：token、Safari fallback、浅深色与减少透明度。
2. 动效基线：统一 spring/press 状态、减少动态效果。
3. 空间层级：z-index 规范、侧栏/面板连续转场。
4. 手势交互：轨道、长按、拖动和冲突测试。
5. 性能治理：低效果模式、滚动/视频并发测试。
6. 融合验收：iPad Safari 横竖屏、分屏、浅深色、视频播放场景。

## 验收矩阵

| 场景 | 必须通过 |
|---|---|
| iPad Safari 横屏/竖屏 | 导航、侧栏、页面滚动和点击正常 |
| 浅色/深色 | 玻璃边界与文字对比度清晰 |
| 不支持 SVG 折射 | 自动回退，不出现空白或不可读玻璃 |
| 减少透明度 | 使用更实的底色和清晰边框 |
| 减少动态效果 | 无非必要弹跳、惯性和持续动效 |
| 播放视频时 | 玻璃与动效不明显干扰播放 |
| 触控/键盘/触控板 | 关键功能均有可访问的操作方式 |
| 低功耗/低性能设备 | 自动降低装饰效果，功能保持完整 |
