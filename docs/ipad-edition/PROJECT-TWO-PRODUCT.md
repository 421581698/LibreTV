# LibreTV iPad Edition — 项目二：完整产品建设

状态：开发与自动化验收进行中。此项目基于项目一独立基础分支，在专属产品分支上构建完整 iPad 影院产品。

## 范围

本项目只建设 iPad 版本，不扩展其他设备形态。产品 UI、导航、样式、页面路由均位于 `/ipad-edition` 独立命名空间；允许复用既有服务端数据 API、搜索服务、媒体详情逻辑、播放器内核和本地数据库能力。

## 页面与能力

| 页面/模块 | 实现方式 | 数据来源 |
|---|---|---|
| 影院首页 | 宽幅精选 Hero、继续观看、热门电影、热门剧集、最新内容、新番轨道 | 豆瓣 API、60s 热榜备用、Bangumi 日历 |
| 电影 | 热门/最新/高分切换、分页、真实海报 | `/api/douban` |
| 电视剧 | 热门/最新/高分切换、分页、真实海报 | `/api/douban` |
| 动漫 | 新番日历与真实番剧条目 | `/api/bangumi/calendar` |
| 搜索 | 聚合已启用点播源、真实搜索结果、进入详情 | `/api/search` |
| 详情 | 复用既有真实详情、分集、收藏与分享逻辑 | `/api/detail` 与本地数据库 |
| 播放 | iPad Edition 专属播放路由，复用现有播放器能力 | 既有播放服务与播放内核 |
| 资料库 | 本地收藏读取、打开详情、移出收藏 | IndexedDB / Dexie |
| 设置 | 连接现有数据源和播放设置能力 | 既有设置状态与 API |

## 数据真实性规则

- 首页和分类只展示 API 返回的真实条目。
- 不用假海报、随机内容或静态样例填充真实内容区域。
- 推荐接口失败时允许使用已配置的真实热榜备用接口；备用接口也失败时显示错误/空状态。
- 搜索结果必须来自当前启用且通过 URL 安全校验的点播源。
- 影片详情和播放必须使用源返回的真实 ID、详情和播放地址。

## 视觉与交互

- 产品定位：**LibreTV · Cinema Experience**。以 Apple TV 的沉浸式影院氛围为体验参考，不复制其品牌 UI。
- 首页采用深色连续影院画布；Hero 必须真正全视口宽（100vw），不得被居中的内容容器收窄或与下方轨道拼成普通卡片。
- Hero 使用真实推荐条目的背景图/海报；焦点切换时同步切换真实影片标题、评分和 artwork。没有真实横幅时允许使用真实海报作为视觉来源，但不得伪造电影剧照。
- 顶部悬浮胶囊仅保留三个入口：侧边栏、首页、搜索。电影/剧集/动漫分类、资料库与设置放入侧边栏。
- 今日热门、继续观看、剧集、新片与新番采用横向电影画廊；焦点、按压、滚动与转场保持克制，并支持触控、键盘与减少动态效果偏好。
- 豆瓣/Bangumi 推荐条目不是点播源详情 ID。点击推荐影片后先通过真实搜索结果解析可用点播源，再进入沉浸式详情与播放；不得拼造 source/id 或跳过授权/资源验证。
- iPad 横屏、竖屏及 Safari 安全区域必须分别适配；顶部导航、Hero 文案、海报与分页器不得相互遮挡。
- Sidebar、顶部悬浮胶囊和页面内容共享同一 iPad Edition 路由布局；Hero、海报轨道、分类网格、搜索结果和本地资料库使用独立 `ipad-edition__*` 样式命名空间。
- 提供加载、错误、空数据状态；支持键盘/触控可访问性与减少动态效果、减少透明度偏好。

## 六大方向：iPad Design Engine

本产品将六个技术方向统一纳入 iPad Edition Design Engine，不再分散堆叠页面级特效：

1. Apple Liquid Glass 材质：折射增强、边缘高光、环境光与 Safari 兼容降级。
2. 动态物理动画：弹簧、惯性、形变与触摸反馈。
3. 空间化 UI：内容层、导航层、浮层、侧栏与模态层级。
4. 自适应材质：浅色/深色、动态海报背景、减少透明度与窗口尺寸变化。
5. 高性能渲染：Safari/WebKit、视频播放并发、低功耗设备与效果降级。
6. 交互细节：点击、长按、拖动、滑动、转场、键盘与触控板。

完整设计规范、实施顺序和验收矩阵见 [IPAD-DESIGN-ENGINE-ROADMAP.md](./IPAD-DESIGN-ENGINE-ROADMAP.md)。

当前只将共享 token、Safari fallback、按压反馈、焦点可见性和减少透明度降级作为本轮基础能力；完整折射、惯性拖拽和复杂手势仍须分阶段实现并通过真实 iPad Safari 验收。不得将设计路线图误报为全部功能已经完成。
