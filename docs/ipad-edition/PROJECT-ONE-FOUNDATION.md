# LibreTV iPad Edition — 项目一：独立版本基础建设

状态：基础架构实施中。本文是项目一的范围与 UI 设计冻结基线。

## 产品边界

LibreTV iPad Edition 是独立的 iPad 产品版本。它拥有独立入口、应用壳、导航、样式命名空间、布局规则、构建与验收流程。不得将其他设备的 UI 当作基底再通过媒体查询改造。

本项目仅建设 iPad 版本，不扩展为多设备项目。共享现有业务数据 API、媒体资源数据模型和播放器底层能力时，必须保持 iPad 展示层独立。

## 已确认的 UI 设计基线

### 影院式首页

- 采用影院大堂式沉浸首页，而非普通列表页。
- 顶部为悬浮毛玻璃导航。
- Hero 为宽幅影视背景区域，标题、简介和主要操作位于左下区域。
- Hero 下方为精选、继续观看、热门电影、热门剧集等横向内容轨道。
- 海报必须来自真实推荐数据；没有数据时显示空状态，不得用虚构海报填充。

### 冻结尺寸

以上是已讨论确认的视觉基线。后续若需调整，必须有明确设计评审记录，不能在实现中自行改值。

### V4.2 自适应导航规则

- 宽窗口：常驻左侧 Sidebar，初始宽度 288px，右侧 1px 分隔线，内部水平间距 8px。
- Sidebar 当前选中项采用蓝色胶囊背景。
- Sidebar 可收起；收起后使用顶部居中的悬浮毛玻璃胶囊导航。
- 窄窗口或竖屏：使用顶部居中悬浮胶囊；Sidebar 仅作为 Overlay 按需呼出。
- 播放器沉浸播放时隐藏导航。
- 导航项：搜索、首页、电影、电视剧、动漫、资料库；设置与关于位于 Sidebar 底部。

### 影院容器档位

- 小于 700px：不激活影院应用布局。
- 700–1023px：compact，隐藏常驻 Sidebar，显示顶部胶囊导航；焦点遍历优先纵向。
- 1024px 及以上：stage，显示 Sidebar 和顶部胶囊导航；横向内容轨道维持横向焦点方向。
- 不设置 1440px 上限。

## 项目一交付范围

1. 独立 /ipad-edition 入口与 iPad 专属应用壳。
2. iPad 专属 CSS 命名空间和设计 tokens。
3. 独立导航/布局契约及基础容器档位。
4. 与全局导航壳隔离，避免共享导航覆盖 iPad 体验。
5. 独立 Preview 配置与 iPad 专属 CI/视觉验收入口。
6. 对已有 iPad 基础模块进行审查后迁移，不整体复制历史分支。

## 项目一不交付的页面内容

完整首页数据接入、真实 Hero 内容、影视详情页、搜索页、分类页、播放器完整 UI、个人空间和设置页面属于项目二。项目一只交付这些页面未来使用的独立应用基础，不以静态占位冒充完整产品。
