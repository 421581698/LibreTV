# 外部点播 API 候选源

本目录用于 LibreTV 的外部点播 API 评估，不代表对第三方内容的版权授权，也不代表已完成真实播放验收。

## 文件

- `external-vod-candidates.json`：完整候选目录，包含六个此前讨论的 API 及各自验证状态。
- `verified-api-subscription.json`：仅包含本轮实际观察到有效 JSON 列表响应的三个 API（U酷、如意、非凡），供管理员手动导入测试。

|---|---|---|---|---|

“本轮未能验证”不等于接口失效。接口列表返回成功也不等于详情、播放线路或内容权利已验证。

## 导入方式

合并并部署此分支后，可在 LibreTV「设置 → 资源站 → 资源订阅」中手动添加：

`/source-catalog/verified-api-subscription.json`

也可直接在部署站点打开该 JSON，再由管理员按现有资源订阅流程导入。该订阅不会被设置为全体用户的默认源；是否启用由管理员决定。

## 4K 规则

不得依据资源站名称、文件名、海报标签或 M3U8 manifest 声明直接标记为真 4K。必须通过 PlayerShell 播放期间的解码视频尺寸观测到 3840×2160，并保留观测次数、时长和失败原因。HDR、HEVC、码率另行记录。

## 安全与版权

- 只允许通过现有 SSRF / 公网 DNS 校验和受限 fetch 管线访问上游。
- 不绕过登录、付费墙、验证码、DRM 或访问控制。
- 在管理员确认内容授权/合法来源前，不应作为默认预置源或生产推荐源。
