# Movies Page Contract

- Purpose: browse and filter movie catalog.
- Hierarchy: page title/filters, content categories, poster grid/list, pagination or load-more controls.
- Data: use existing movie catalog/search endpoints and actual metadata/posters.
- Visual: poster ratios, title readability, metadata density, loading/empty/error states follow root DESIGN.md.
- Responsive: adapt columns and filter controls without hiding primary browse actions.
- Protected: catalog API, filter semantics, pagination, navigation, and playback handoff.
- Acceptance: filter/search interactions, empty/error states, poster loading, desktop/tablet/phone and both themes.
