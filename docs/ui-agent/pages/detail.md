# Detail Page Contract

- Purpose: communicate title information and enable reliable playback/source selection.
- Hierarchy: artwork/title, essential metadata, synopsis, available sources/episodes, primary playback action.
- Data: preserve existing detail and source APIs; show only actual returned metadata.
- Visual: readable metadata, image crop, long synopsis, selected episode/source states.
- Responsive: artwork and metadata reflow without obscuring primary play action.
- Protected: source selection, episode selection, player handoff, APIs, and persistence.
- Acceptance: missing metadata, long titles, multi-episode content, source switching, desktop/tablet/phone.
