# Anime Page Contract

- Purpose: discover anime series and schedules.
- Hierarchy: page identity, schedule/category controls, real anime content, poster cards.
- Data: reuse existing Bangumi/calendar and anime data sources; do not fabricate schedule entries or images.
- Visual: use root semantic tokens; keep schedule metadata legible and distinguish date/status states.
- Responsive: schedule and card layout must remain usable on phone and tablet.
- Protected: Bangumi/API contracts, schedule ordering, route behavior, and playback handoff.
- Acceptance: schedule changes, loading/empty/error, actual posters, desktop/tablet/phone and both themes.
