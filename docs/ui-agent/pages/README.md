# LibreTV Page Design Contracts

Each page contract extends root `DESIGN.md`. It may refine local layout and components, but cannot override global accessibility, responsive, safety, or protected-functionality rules.

Required contracts:
- `home.md`
- `movies.md`
- `anime.md`
- `search.md`
- `detail.md`
- `player.md`
- `my-space.md`
- `settings.md`
- `ui-studio.md`

Each contract documents purpose, hierarchy, data provenance, layout, tokens, responsive behavior, interaction states, protected logic, and acceptance evidence. Existing approved page baselines remain authoritative until explicitly changed by the user.
