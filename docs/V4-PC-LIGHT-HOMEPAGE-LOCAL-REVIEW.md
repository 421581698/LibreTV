# LibreTV V4 PC Light Homepage — 本地视觉验收

## 运行环境

- Node.js：使用仓库 CI 当前支持的 Node 版本
- 包管理器：npm
- 首页本地端口：8080

## 启动

在仓库根目录执行：

```bash
npm ci
npm run dev
```

浏览器访问：

```text
http://localhost:8080
```

如本地没有 npm lockfile 或 npm ci 无法解析依赖，先执行 `npm install`，再执行 `npm run dev`。

## 建议的截图条件

1. 桌面浏览器窗口宽度建议 1440px 或 1600px，高度 1000px 左右。
2. 浏览器缩放保持 100%，使用浅色主题。
3. 打开首页根路径 `/`，不要带 `?s=` 或 `?q=` 搜索参数。
4. 截取从 Header 到 Hero，再向下包含“今日推荐”和“继续观看”骨架的页面。
5. 检查 Header 六项导航：首页、影视、动漫、直播、资源、我的；首页为白色圆角高亮。
6. 检查 Friday 金色球在右上角悬浮，带绿色状态点与提示气泡；点击球体应调用原 Friday V3 交互入口。

## CSS 隔离说明

V4 页面使用独立根节点 `.v4-home` 和独立样式文件 `src/app/v4-homepage.css`。旧首页专属的 `.legacy-home` / `.home-v2` 选择器不应匹配该根节点。本阶段不删除播放器、Friday、资源接口或全局基础样式。

## 本阶段范围

这是里程碑 A 的视觉骨架：Header、Hero、导航交互、轮播指示器，以及两排内容区的布局占位。今日推荐真实海报与继续观看真实播放记录将在里程碑 B 接入；当前骨架卡片是明确的布局占位，不代表真实影片数据。
